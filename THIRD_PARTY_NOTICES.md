# Third-party components

ConvoMux remains UNLICENSED/private until its owner chooses a publication policy.
These upstream licenses do not change ConvoMux's license.

- **msteams 0.2.1**, Shotaro Nakamura, MIT. Source: https://github.com/nakasyou/teams-api/tree/04721b476a200e71e0da8d4958e27385d4787e7b . Full text: `vendor/licenses/msteams-MIT.txt` and `node_modules/msteams/LICENSE`. The npm package, its existing CLI code, and its dependency tree are bundled without modification. cmx only invokes the read/login CLI; it exposes no MCP command.
- **slk v0.2.0**, OSO DevOps, MIT as declared by release Cargo.toml. Release: https://github.com/osodevops/slack-cli/releases/tag/v0.2.0 . Binary source revision: `f8ce5c0d3ecb12602cbeb0469c555ce47eeccbf1`. The release tag/archives contain no LICENSE file. `vendor/licenses/slk-MIT.txt` is the upstream license text at `66c0f26492cb049ea287f6463d8a19eb97ec7cb9`, where the license file was subsequently added. Before public redistribution, the owner must review Rust dependency license/NOTICE obligations against the release's Cargo.lock; upstream did not supply a complete binary third-party notice bundle. This remains a publication blocker, not a claim that this review is complete.
- **simple-update-notifier 2.0.0**, Alex Brazier, MIT. https://github.com/alexbrazier/simple-update-notifier . Its public npm dist-tags request pattern informed `src/update-worker.ts`; license: `vendor/licenses/simple-update-notifier-MIT.txt`. The notification worker was adapted to bound response size/time, cache failed attempts, suppress authentication and run separately. The upstream package is not a runtime dependency.
- **semver 7.7.3**, npm contributors, ISC. The implementation and license are included in `node_modules/semver`. It handles comparisons including prereleases.

The npm dependency tree is bundled from package-lock.json, preserving dependency package metadata and license files under node_modules. Review that tree, the upstream sources, and the Rust binary dependencies when changing any pinned version. backend-contracts.json records artifact sources, hashes and the inspected contracts.

Evaluated update-notifier 7.3.1 and its latest-version/package-json implementation: the latter automatically reads npm registry credentials; update-notifier also retries failed checks on every invocation and can print a sudo suggestion after a config permission error. update-check 1.5.4 also loads registry credentials and uses lexical numeric comparison. simple-update-notifier performs a credential-free public registry GET, but has no hard timeout/body bound, no detached worker or reusable returned notice, and caches only successful attempts. Those constraints require the small bounded adaptation used here; the SemVer algorithm is reused rather than reimplemented.
